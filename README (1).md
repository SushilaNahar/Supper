# Supper

A quiet little meal log. Log what you eat for every meal, add optional details, and browse by day, week or month. Includes search, food suggestions, streaks and stats.

Everything is saved in your own browser (on your device). Nothing is uploaded anywhere.

## Use it

Open the page, then on iPhone tap Share → **Add to Home Screen** so it opens like an app.

## Back up your data

Tap **Backup & restore** and choose **Save backup to Files**. Do this regularly: Safari can clear a website's saved data if it isn't used for a while, and a backup file is the safe copy. Use **Restore from a backup file** to bring entries back.

## Host it on GitHub Pages

1. Put `index.html` in the root of a repository.
2. Repository **Settings → Pages → Build and deployment**: set Source to *Deploy from a branch*, branch `main`, folder `/ (root)`.
3. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.
